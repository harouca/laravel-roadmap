# Roadmap de estudos

Este roadmap organiza o aprendizado em etapas progressivas. Os itens marcados representam conteúdo documental disponível, não necessariamente funcionalidades já implementadas.

## Etapa 1 — Fundamentos

- [x] Entender a proposta do Laravel e os pré-requisitos de estudo.
- [x] Conhecer a estrutura padrão de uma aplicação Laravel.
- [x] Compreender o papel do PHP Artisan.
- [x] Disponibilizar laboratórios iniciais de Artisan, rotas e Controller.

## Próxima etapa — Primeira aplicação

- [ ] Preparar o ambiente de desenvolvimento.
- [ ] Criar o projeto Laravel 13 em `project/`.
- [ ] Executar a aplicação localmente.
- [ ] Conhecer o fluxo básico entre rota, Controller e view.

## Etapas futuras

Os próximos tópicos serão definidos conforme o projeto evoluir. Entre os assuntos previstos estão rotas, Controllers, Blade, banco de dados, Eloquent, validação, autenticação, testes e publicação da aplicação.

> Novos capítulos devem ser adicionados apenas quando a etapa correspondente começar, evitando uma estrutura extensa sem conteúdo desenvolvido.
